# CodeAlpha_Calculator
Calculator Web App
This project is a fully responsive Calculator Web Application built using HTML, CSS, and JavaScript. It features both a Basic Calculator and a Scientific Calculator within the same interface. The calculator is designed to be clean, intuitive, and accessible on all devices — from desktops to mobile screens.

Features
Basic Calculator: Perform essential arithmetic operations like addition, subtraction, multiplication, and division.

Scientific Calculator: Access advanced mathematical functions such as sine, cosine, tangent, logarithms, exponentials, square roots, and more.

Light and Dark Mode: Seamlessly switch between light and dark themes for a personalized experience.

Fully Responsive Design: Works smoothly on desktops, tablets, and mobile devices.

Interactive UI: Clean, modern interface with smooth transitions and user-friendly button layouts.

Error Handling: Displays appropriate messages for invalid inputs and prevents common calculation mistakes.

Technologies Used
HTML — for structuring the content.

CSS — for styling, layout, and responsive design.

JavaScript — for handling calculations, dynamic UI interactions, and theme toggling
